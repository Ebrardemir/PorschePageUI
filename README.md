Bu proje, Android Bootcamp kapsamında hazırladığım 3. ödev olan bir tasarım çalışmasıdır. Uygulama, modern Android tasarım prensiplerine uygun olarak geliştirilmiş ve aşağıdaki özellikleri içermektedir:

✨ Özellikler

🎨 Renk Tanımlama
Uygulama genelinde tutarlı tema için colors.xml dosyasıyla özel renk paletleri tanımlanmıştır.

🅰️ Özel Font Kullanımı
Uygulamada görsel bütünlük sağlamak için res/font klasörü altında özel yazı tipleri tanımlanmıştır.

🌍 Çoklu Dil Desteği
strings.xml dosyaları values-tr, values gibi klasörlerle çoklu dil (Türkçe ve İngilizce) desteği sağlanmıştır.

📱 Çoklu Ekran Desteği
layout-small, layout-large, layout-xlarge gibi dizinlerle farklı cihaz boyutları için uyumlu arayüzler tasarlanmıştır.

🌙 Dark Mode Desteği
values-night/colors.xml kullanılarak karanlık tema desteği eklenmiştir.
